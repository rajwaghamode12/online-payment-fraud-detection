AI-Based Online Payment Fraud Detection

About The Project

This is a college-level demonstration project designed to show how Machine Learning can be used to detect fraudulent online transactions in real-time.

How it Works
  1. Data Collection: The system takes transaction details (amount, time, device, location, etc.).
  2. Preprocessing: Data is scaled and encoded so the ML model can understand it.
  3. Prediction: A trained Random Forest Classifier analyzes the data and predicts whether it is Genuine or Fraudulent.
  4. Risk Scoring: The raw probability is converted into a 0-100 risk score and categorized into Low, Medium, or High Risk.
Technologies Used
  • Backend: Python, Flask, SQLite, SQLAlchemy
  • Machine Learning: Scikit-Learn, Pandas, NumPy, Imbalanced-Learn
  • Frontend: HTML5, CSS3, Bootstrap 5, Chart.js
